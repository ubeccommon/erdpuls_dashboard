{% if lang == 'de' %}Erhaltender Beitrag{% elif lang == 'pl' %}Wkład podtrzymujący{% else %}Sustaining Contribution{% endif %}

{% if lang == 'de' %} Wer den vollen Preis zahlt, „kauft nicht einfach eine Dienstleistung". Sie leisten einen erhaltenden Beitrag, der die Betriebskosten deckt und gleichzeitig Kapazitäten für andere zur Teilnahme schafft. Dies ist pflanzliche Großzügigkeit in wirtschaftlicher Form — mehr geben als nehmen. {% elif lang == 'pl' %} Ci, którzy płacą pełną stawkę, nie „kupują po prostu usługi". Wnoszą wkład podtrzymujący, który pokrywa koszty operacyjne, jednocześnie tworząc możliwości uczestnictwa dla innych. To roślinna hojność w formie ekonomicznej — dawanie więcej niż branie. {% else %} Those who pay the full rate are not simply "buying a service." They are making a sustaining contribution that covers operational costs while creating capacity for others to participate. This is plant generosity in economic form — giving more than taking. {% endif %}

{% if lang == 'de' %}Gemeinschaftsgetragene Teilnahme{% elif lang == 'pl' %}Uczestnictwo wspierane przez wspólnotę{% else %}Community-Held Participation{% endif %}

{% if lang == 'de' %} Der unterstützte Beitrag (50-80% des vollen Preises) erkennt wirtschaftliche Realitäten an, ohne Wohltätigkeitsdynamiken zu schaffen. Teilnehmende wählen selbst basierend auf echtem Bedarf — kein Nachweis erforderlich, keine Fragen gestellt. Dieses Vertrauen ist wesentlich. {% elif lang == 'pl' %} Stawka wspierana (50-80% pełnej ceny) uznaje realia ekonomiczne bez tworzenia dynamiki dobroczynności. Uczestnicy sami wybierają w oparciu o rzeczywistą potrzebę — bez wymaganego dowodu, bez pytań. To zaufanie jest kluczowe. {% else %} The supported rate (50-80% of full rate) acknowledges economic reality without creating charity dynamics. Participants self-select based on genuine need — no proof required, no questions asked. This trust is essential. {% endif %}

{% if lang == 'de' %}Fähigkeitenbasierter Austausch{% elif lang == 'pl' %}Wymiana oparta na umiejętnościach{% else %}Skills-Based Exchange{% endif %}

{% if lang == 'de' %} Dieser Weg erkennt an, dass Wert in vielen Formen kommt. Zeit, Fähigkeiten, Wissen, Arbeit — alles sind echte Beiträge, die die Gemeinschaft unterstützen. Teilnehmende verhandeln spezifische Beiträge, die einige oder alle finanziellen Kosten ausgleichen. {% elif lang == 'pl' %} Ta ścieżka uznaje, że wartość przychodzi w wielu formach. Czas, umiejętności, wiedza, praca — wszystko to prawdziwe wkłady wspierające społeczność. Uczestnicy negocjują konkretne wkłady, które kompensują część lub całość kosztów finansowych. {% else %} This pathway recognizes that value comes in many forms. Time, skill, knowledge, labor — all are genuine contributions that support the community. Participants negotiate specific contributions that offset some or all of the financial cost. {% endif %}

Dies schließt den reziproken Kreislauf: Umweltpflege erzeugt Wert, der weiteres Lernen ermöglicht. {% elif lang == 'pl' %} Tokeny UBECrc zdobyte poprzez monitoring środowiska i naukę obywatelską można wymieniać na uczestnictwo w kursach, wydarzeniach i usługach. To zamyka pętlę wzajemności: opieka nad środowiskiem generuje wartość umożliwiającą dalszą naukę. {% else %} UBECrc tokens earned through environmental monitoring and citizen science can be exchanged for participation in courses, events, and services. This closes the reciprocal loop: environmental stewardship generates value that enables further learning. {% endif %}

{% if lang == 'de' %} Teilnehmende können Wege kombinieren. Zum Beispiel: 50% unterstützter Beitrag in Euro + 50% in UBECrc-Tokens, oder 2 Stunden Gartenarbeit + verbleibender Betrag in Euro. Diese Flexibilität stellt sicher, dass niemand aufgrund eindimensionaler wirtschaftlicher Einschränkungen ausgeschlossen wird. {% elif lang == 'pl' %} Uczestnicy mogą łączyć ścieżki. Na przykład: 50% stawki wspieranej w euro + 50% w tokenach UBECrc, lub 2 godziny pracy w ogrodzie + pozostała kwota w euro. Ta elastyczność zapewnia, że nikt nie jest wykluczony z powodu jednowymiarowych ograniczeń ekonomicznych. {% else %} Participants can combine pathways. For example: pay 50% supported rate in euros + 50% in UBECrc tokens, or contribute 2 hours of garden work + remaining balance in euros. This flexibility ensures no one is excluded due to single-dimension economic constraints. {% endif %}
