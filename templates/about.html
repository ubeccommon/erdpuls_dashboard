{% if lang == 'de' %}Die Einsicht{% elif lang == 'pl' %}Wgląd{% else %}The Insight{% endif %}

{% if lang == 'de' %} Die meisten Preismodelle — selbst progressive wie Staffelpreise — funktionieren immer noch auf individueller Transaktionsbasis. Jede Person berechnet, was sie zahlen kann oder sollte. Dies schafft subtile Hierarchien: diejenigen, die den vollen Preis zahlen, diejenigen, die „Unterstützung" erhalten, diejenigen, die „Stipendien" brauchen. {% elif lang == 'pl' %} Większość modeli cenowych — nawet progresywnych, takich jak skale ruchome — nadal działa na zasadzie indywidualnej transakcji. Każda osoba oblicza, ile może lub powinna zapłacić. Tworzy to subtelne hierarchie: ci, którzy płacą pełną cenę, ci, którzy otrzymują „wsparcie", ci, którzy potrzebują „stypendiów". {% else %} Most pricing models — even progressive ones like sliding scales — still operate on an individual transaction basis. Each person calculates what they can or should pay. This creates subtle hierarchies: those who pay full price, those who receive "support," those who need "scholarships." {% endif %}

{% if lang == 'de' %} Was wäre, wenn wir das anders angehen würden? Was wäre, wenn die Gemeinschaft kollektiv jedes Angebot ins Sein hielte? {% elif lang == 'pl' %} A gdyby podejść do tego inaczej? Co jeśli społeczność kolektywnie utrzymywałaby każdą ofertę w bycie? {% else %} What if we approached this differently? What if the community collectively held each offering into being? {% endif %}

{% if lang == 'de' %}Philosophische Grundlage{% elif lang == 'pl' %}Podstawy filozoficzne{% else %}Philosophical Foundation{% endif %}

Ubuntu

{% if lang == 'de' %}„Ich bin, weil wir sind."{% elif lang == 'pl' %}„Jestem, ponieważ jesteśmy."{% else %}"I am because we are."{% endif %}

{% if lang == 'de' %} Die afrikanische Philosophie Ubuntu lehrt, dass individuelle Identität aus der Gemeinschaftsbeziehung entsteht. Das Kollektive Threshold-Modell verkörpert dieses Prinzip ökonomisch: das Angebot existiert, weil wir es gemeinsam ermöglichen. {% elif lang == 'pl' %} Afrykańska filozofia Ubuntu uczy, że tożsamość jednostki wyłania się z relacji wspólnotowych. Model Zbiorowego Progu ucieleśnia tę zasadę ekonomicznie: oferta istnieje, ponieważ wspólnie ją umożliwiamy. {% else %} The African philosophy of Ubuntu teaches that individual identity emerges from community relationship. The Collective Threshold Model embodies this principle economically: the offering exists because we collectively make it so. {% endif %}

{% if lang == 'de' %}Pflanzenweisheit{% elif lang == 'pl' %}Mądrość roślin{% else %}Plant Wisdom{% endif %}

{% if lang == 'de' %} In einem Wald fließen Nährstoffe durch Mykorrhiza-Netzwerke von Bäumen mit Überfluss zu Bäumen mit Bedarf. Kein Baum wird stigmatisiert, weil er empfängt. Kein Baum wird gelobt, weil er gibt. Der Wald ist dieses Fließen. {% elif lang == 'pl' %} W lesie składniki odżywcze przepływają przez sieci mikoryzowe od drzew z obfitością do drzew w potrzebie. Żadne drzewo nie jest piętnowane za przyjmowanie. Żadne drzewo nie jest chwalone za dawanie. Las jest tym przepływem. {% else %} In a forest, nutrients flow through mycorrhizal networks from trees with abundance to trees with need. No tree is stigmatized for receiving. No tree is praised for giving. The forest is this flowing. {% endif %}

{% if lang == 'de' %}Vertrauen als Grundlage{% elif lang == 'pl' %}Zaufanie jako fundament{% else %}Trust as Foundation{% endif %}

{% if lang == 'de' %} Dieses Modell erfordert — und kultiviert — Vertrauen. Wir vertrauen darauf, dass Menschen entsprechend ihrer echten Kapazität und ihrem Gewissen beitragen. Wir vertrauen darauf, dass Überfluss von denen fließt, die ihn haben. Wir vertrauen darauf, dass die Gemeinschaft das Angebot trägt. {% elif lang == 'pl' %} Ten model wymaga — i kultywuje — zaufanie. Ufamy, że ludzie wniosą wkład zgodnie ze swoimi prawdziwymi możliwościami i sumieniem. Ufamy, że obfitość popłynie od tych, którzy ją mają. Ufamy, że społeczność utrzyma ofertę. {% else %} This model requires — and cultivates — trust. We trust that people will contribute according to their genuine capacity and conscience. We trust that abundance will flow from those who have it. We trust that the community will hold the offering. {% endif %}
