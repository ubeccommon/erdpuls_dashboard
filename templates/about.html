{% if lang == 'de' %} Ein Lebendes Labor, in dem Technologie und Natur zusammenwirken {% elif lang == 'pl' %} Żywe Laboratorium, gdzie technologia i natura współpracują {% else %} A Living Laboratory where technology and nature collaborate {% endif %}

{% if lang == 'de' %} Erdpuls Müllrose ist keine Schulgarten. Es ist eine gemeinschaftliche, generationenübergreifende Initiative — ein 3.000 Quadratmeter großes "Living Lab" und Zentrum für Nachhaltigkeitskompetenz, Bürgerwissenschaft und Reziproke Ökonomie. {% elif lang == 'pl' %} Erdpuls Müllrose to nie jest ogród szkolny. To wspólnotowa, międzypokoleniowa inicjatywa — 3000 metrów kwadratowych "Living Lab" i Centrum Kompetencji Zrównoważonego Rozwoju, Nauki Obywatelskiej i Ekonomii Wzajemności. {% else %} Erdpuls Müllrose is not a school garden. It is an interdependent, intergenerational community initiative — a 3,000 square meter "Living Lab" and Center for Sustainability Literacy, Citizen Science and Reciprocal Economics. {% endif %}

{% if lang == 'de' %}Die Vision{% elif lang == 'pl' %}Wizja{% else %}The Vision{% endif %}

{% if lang == 'de' %} „Während wir lernen, wie eine Pflanze zu denken, entdecken wir, dass Technologie und Natur keine Gegensätze sind, sondern komplementäre Ausdrücke derselben schöpferischen Kräfte, die unsere Welt formen." {% elif lang == 'pl' %} „Ucząc się myśleć jak roślina, odkrywamy, że technologia i natura nie są przeciwieństwami, lecz komplementarnymi wyrazami tych samych twórczych sił, które kształtują nasz świat." {% else %} "As we learn to think like a plant, we discover that technology and nature are not opposites but complementary expressions of the same creative forces that shape our world." {% endif %}

{% if lang == 'de' %} Wir leben in einer Zeit tiefgreifender Entfremdung und ebenso tiefgreifender Notwendigkeit zur Wiederverbindung. Kinder verbringen weniger Zeit im Freien als jede vorherige Generation der Menschheitsgeschichte, gerade wenn ökologische Herausforderungen ein tieferes Verständnis erfordern. Erwachsene haben die Rhythmen des jahreszeitlichen Bewusstseins verloren. Technologie vermittelt zunehmend unsere Erfahrung der Realität, obwohl wir unvermittelte sinnliche Verbindung zur lebenden Welt brauchen. {% elif lang == 'pl' %} Żyjemy w czasach głębokiego odłączenia i równie głębokiej potrzeby ponownego połączenia. Dzieci spędzają mniej czasu na zewnątrz niż jakakolwiek poprzednia generacja w historii ludzkości, właśnie gdy wyzwania ekologiczne wymagają głębszego zrozumienia. Dorośli utracili rytmy sezonowej świadomości. Technologia coraz bardziej pośredniczy w naszym doświadczaniu rzeczywistości, choć potrzebujemy bezpośredniego zmysłowego połączenia z żywym światem. {% else %} We live in a time of profound disconnection and equally profound need for reconnection. Children spend less time outdoors than any previous generation in human history, even as environmental challenges demand deeper ecological understanding. Adults have lost the rhythms of seasonal awareness. Technology increasingly mediates our experience of reality, even as we need unmediated sensory connection to the living world. {% endif %}

{% if lang == 'de' %} Erdpuls Müllrose ist eine lebendige Antwort auf eine entscheidende Frage unserer Zeit: Wie können wir die mächtigen Werkzeuge moderner Technologie nutzen, um unsere Verbindung zur natürlichen Welt zu vertiefen statt zu vermindern? Wie können wir Wirtschaftssysteme schaffen, die ökologische Fürsorge als wirklich wertvoll anerkennen? {% elif lang == 'pl' %} Erdpuls Müllrose jest żywą odpowiedzią na kluczowe pytanie naszych czasów: Jak możemy wykorzystać potężne narzędzia nowoczesnej technologii, aby pogłębić, a nie zmniejszyć naszą więź ze światem przyrody? Jak możemy tworzyć systemy ekonomiczne, które uznają opiekę nad środowiskiem za naprawdę wartościową? {% else %} Erdpuls Müllrose represents a living answer to a critical question facing humanity: How can we use the powerful tools of modern technology to deepen rather than diminish our connection with the natural world? How can we create economic systems that recognize environmental stewardship as genuinely valuable? {% endif %}
