{% if lang == 'de' %}Über Erdpuls{% elif lang == 'pl' %}O Erdpuls{% elif lang == 'uk' %}Про Erdpuls{% else %}About Erdpuls{% endif %}

{% if lang == 'de' %} Ein Lebendes Labor, in dem Technologie und Natur zusammenwirken {% elif lang == 'pl' %} Żywe Laboratorium, gdzie technologia i natura współpracują {% elif lang == 'uk' %}Жива лабораторія, де технологія та природа співпрацюють{% else %} A Living Laboratory where technology and nature collaborate {% endif %}

{% if lang == 'de' %} Erdpuls ist keine Schulgarten. Es ist eine gemeinschaftliche, generationenübergreifende Initiative — ein offenes "Living Lab" und Zentrum für Nachhaltigkeitskompetenz, Bürgerwissenschaft und Reziproke Ökonomie. {% elif lang == 'pl' %} Erdpuls to nie jest ogród szkolny. To wspólnotowa, międzypokoleniowa inicjatywa — otwarte "Living Lab" i Centrum Kompetencji Zrównoważonego Rozwoju, Nauki Obywatelskiej i Ekonomii Wzajemności. {% elif lang == 'uk' %}Erdpuls — це не шкільний сад. Це взаємозалежна, міжпоколіннєва громадська ініціатива — відкрита «Жива лабораторія» та осередок екологічної грамотності, громадянської науки й економіки взаємності.{% else %} Erdpuls is not a school garden. It is an interdependent, intergenerational community initiative — an open "Living Lab" and Center for Sustainability Literacy, Citizen Science and Reciprocal Economics. {% endif %}

{% if lang == 'de' %}Die Vision{% elif lang == 'pl' %}Wizja{% elif lang == 'uk' %}Візія{% else %}The Vision{% endif %}

{% if lang == 'de' %} „Während wir lernen, wie eine Pflanze zu denken, entdecken wir, dass Technologie und Natur keine Gegensätze sind, sondern komplementäre Ausdrücke derselben schöpferischen Kräfte, die unsere Welt formen." {% elif lang == 'pl' %} „Ucząc się myśleć jak roślina, odkrywamy, że technologia i natura nie są przeciwieństwami, lecz komplementarnymi wyrazami tych samych twórczych sił, które kształtują nasz świat." {% elif lang == 'uk' %}«Навчаючись мислити як рослина, ми відкриваємо, що технологія та природа — не протилежності, а взаємодоповнювальні вияви тих самих творчих сил, що формують наш світ.»{% else %} "As we learn to think like a plant, we discover that technology and nature are not opposites but complementary expressions of the same creative forces that shape our world." {% endif %}

{% if lang == 'de' %} Wir leben in einer Zeit tiefgreifender Entfremdung und ebenso tiefgreifender Notwendigkeit zur Wiederverbindung. Kinder verbringen weniger Zeit im Freien als jede vorherige Generation der Menschheitsgeschichte, gerade wenn ökologische Herausforderungen ein tieferes Verständnis erfordern. Erwachsene haben die Rhythmen des jahreszeitlichen Bewusstseins verloren. Technologie vermittelt zunehmend unsere Erfahrung der Realität, obwohl wir unvermittelte sinnliche Verbindung zur lebenden Welt brauchen. {% elif lang == 'pl' %} Żyjemy w czasach głębokiego odłączenia i równie głębokiej potrzeby ponownego połączenia. Dzieci spędzają mniej czasu na zewnątrz niż jakakolwiek poprzednia generacja w historii ludzkości, właśnie gdy wyzwania ekologiczne wymagają głębszego zrozumienia. Dorośli utracili rytmy sezonowej świadomości. Technologia coraz bardziej pośredniczy w naszym doświadczaniu rzeczywistości, choć potrzebujemy bezpośredniego zmysłowego połączenia z żywym światem. {% elif lang == 'uk' %}Ми живемо в час глибокого роз’єднання й такої ж глибокої потреби у відновленні зв’язку. Діти проводять надворі менше часу, ніж будь-яке попереднє покоління в історії людства, саме тоді, коли екологічні виклики вимагають глибшого розуміння. Дорослі втратили ритми сезонного усвідомлення. Технологія дедалі більше опосередковує наш досвід реальності, хоча ми потребуємо безпосереднього чуттєвого зв’язку з живим світом.{% else %} We live in a time of profound disconnection and equally profound need for reconnection. Children spend less time outdoors than any previous generation in human history, even as environmental challenges demand deeper ecological understanding. Adults have lost the rhythms of seasonal awareness. Technology increasingly mediates our experience of reality, even as we need unmediated sensory connection to the living world. {% endif %}

{% if lang == 'de' %} Erdpuls ist eine lebendige Antwort auf eine entscheidende Frage unserer Zeit: Wie können wir die mächtigen Werkzeuge moderner Technologie nutzen, um unsere Verbindung zur natürlichen Welt zu vertiefen statt zu vermindern? Wie können wir Wirtschaftssysteme schaffen, die ökologische Fürsorge als wirklich wertvoll anerkennen? {% elif lang == 'pl' %} Erdpuls jest żywą odpowiedzią na kluczowe pytanie naszych czasów: Jak możemy wykorzystać potężne narzędzia nowoczesnej technologii, aby pogłębić, a nie zmniejszyć naszą więź ze światem przyrody? Jak możemy tworzyć systemy ekonomiczne, które uznają opiekę nad środowiskiem za naprawdę wartościową? {% elif lang == 'uk' %}Erdpuls — це жива відповідь на ключове питання, що постає перед людством: як можна використати потужні інструменти сучасної технології, щоб поглибити, а не послабити наш зв’язок зі світом природи? Як створити економічні системи, що визнають турботу про довкілля справді цінною?{% else %} Erdpuls represents a living answer to a critical question facing humanity: How can we use the powerful tools of modern technology to deepen rather than diminish our connection with the natural world? How can we create economic systems that recognize environmental stewardship as genuinely valuable? {% endif %}
