UBEC Erdpuls

{% if lang == 'de' %} Erdpuls ist das offene Living-Lab-Protokoll von UBEC — ein replizierbares Muster, in dem Bodenbeobachtung, IoT-Sensorik, die 13 Fragen an den Boden und UBECrc-Reziprozität auf realem Grund zusammenkommen. Jede Erdpuls-Initiative ist eine ortsbezogene Umsetzung, getragen von ihrer eigenen Gemeinschaft. {% elif lang == 'pl' %} Erdpuls to otwarty protokół living lab UBEC — powtarzalny wzorzec, w którym obserwacja gleby, czujniki IoT, 13 Pytań do gleby i wzajemność UBECrc spotykają się na realnej ziemi. Każda inicjatywa Erdpuls to wdrożenie oparte na miejscu, prowadzone przez własną społeczność. {% elif lang == 'uk' %} Erdpuls — це відкритий протокол живої лабораторії UBEC: відтворюваний взірець, де спостереження за ґрунтом, сенсори IoT, 13 запитань до ґрунту і взаємність UBECrc поєднуються на реальній землі. Кожна ініціатива Erdpuls — це втілення, прив’язане до місця, яке веде власна громада. {% else %} Erdpuls is UBEC's open living lab protocol — a replicable pattern where soil observation, IoT sensing, the 13 Questions to the Soil, and UBECrc reciprocity come together on real ground. Each Erdpuls initiative is a place-based implementation, run by its own community. {% endif %}
