# initiatives — Per-initiative material

One folder per location-based Erdpuls initiative. Each corresponds to an initiative
route in the app (e.g. `muellrose/` ↔ `/muellrose`). Holds place-specific documents:
the initiative's own whitepaper/vision, particular needs, local funding, partnerships,
and any place-bound material that does NOT belong in the location-agnostic `protocol/` set.

To add an initiative: copy `_TEMPLATE/` to `<initiative-slug>/` and fill it in.
