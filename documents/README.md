# Erdpuls — Documents

Reference documents for the Erdpuls project. **Not served by the app** — this is an
archive/OER library, organised as follows:

| Folder | Holds |
|---|---|
| `_project/` | Project-internal technical docs — status reports, schema documentation, service README. |
| `protocol/` | **Network-level OER** — the location-agnostic Erdpuls protocol documents (whitepaper, models). These describe Erdpuls *as a protocol*, applicable to any initiative. Mirror of `/` in the app. |
| `initiatives/` | **Per-initiative material** — one folder per location-based initiative (e.g. `muellrose/`). Place-specific docs, particular needs, local funding. Mirror of `/<initiative>` in the app. |

**Conventions**
- Each OER document lives in its own folder, with a **per-language sub-folder** (`EN/`, `DE/`, `PL/`, `UK/`).
- Filenames carry the language suffix (`..._EN.md`, `..._DE.odt`) for unambiguous identification even when moved.
